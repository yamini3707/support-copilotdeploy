## Troubleshooting: Audit Logs Page is Blank

If you encounter a blank Audit Logs page in CloudDesk, follow these steps to resolve the issue.

1. **Check User Role**: Ensure that the user accessing the Audit Logs has the Admin role. Only users with this role can view audit logs, which are available exclusively for Enterprise accounts. If the user does not have the Admin role, they will not be able to access the logs.

2. **Navigate to Admin Settings**: Go to the Admin panel and select **Admin → Security**. Here, you can verify user roles and permissions. If necessary, assign the Admin role to the appropriate user.

3. **Refresh the Page**: After confirming the user has the Admin role, refresh the Audit Logs page. Sometimes, a simple refresh can resolve display issues.

4. **Check for Filters**: Ensure that no filters are applied that might limit the view of the logs. Clear any filters and try again.

If the issue persists after these steps, consider reaching out to CloudDesk support for further assistance.
