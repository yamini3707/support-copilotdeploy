# Getting Started with API Keys

API keys are essential for accessing CloudDesk's services programmatically. They serve as unique identifiers that authenticate your requests and ensure secure communication between your application and our platform.

To get started, log in to your CloudDesk account and navigate to the API section in your dashboard. Here, you can generate a new API key. Keep your key confidential, as it grants access to your account and data.

When making API calls, include your API key in the request header. This allows CloudDesk to verify your identity and ensure that your application has the necessary permissions. 

Always monitor your API usage to stay informed about your interactions with our services. For further assistance, consult the API documentation or reach out to our support team.
