# CloudDesk Release Notes — March 2026

## New Features
- **Enhanced Export Options**: Users can now export reports in CSV, PDF, and Excel formats, providing greater flexibility for data analysis and sharing.
- **API Version 2.0**: Introduced a new version of our API with improved endpoints for user management and data retrieval, allowing for more seamless integration with third-party applications.
- **Admin Dashboard Revamp**: The admin dashboard has been redesigned for better usability, featuring customizable widgets and improved navigation for easier access to key metrics.

## Fixes
- **Bug Fix: Export Errors**: Resolved an issue where certain users experienced errors during report exports, ensuring a smoother process.
- **API Rate Limiting**: Fixed a bug that incorrectly applied rate limits, allowing developers to make more API calls without interruptions.
- **Admin User Permissions**: Addressed a permissions issue where some admin users could not access specific settings, ensuring proper access control.

## Performance Improvements
- Optimized backend processes for faster load times across the platform, enhancing overall user experience.
