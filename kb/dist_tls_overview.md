# How CloudDesk Secures API Connections

CloudDesk prioritizes the security of API connections through the use of Transport Layer Security (TLS) and encryption protocols. When data is transmitted between your application and CloudDesk's servers, TLS ensures that the information remains confidential and integral by encrypting the data in transit. This prevents unauthorized access and eavesdropping.

All API calls made to CloudDesk are required to use HTTPS, which is HTTP over TLS. This adds an additional layer of security, ensuring that any data exchanged is protected from interception. 

Furthermore, CloudDesk employs strong encryption algorithms to safeguard sensitive information, such as authentication tokens and user credentials. By regularly updating our security protocols and conducting vulnerability assessments, we maintain a robust defense against potential threats.

In summary, CloudDesk's commitment to using TLS and encryption for API connections ensures that your data remains secure and private throughout its journey.
