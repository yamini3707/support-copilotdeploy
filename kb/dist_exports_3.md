# Archiving Old Projects

Archiving old projects in CloudDesk is a great way to declutter your workspace while preserving important information. When a project is no longer active but may be needed for future reference, archiving allows you to store it safely without cluttering your current project list.

To archive a project, navigate to your project dashboard and select the project you wish to archive. Look for the archive option, which will move the project to a dedicated archive section. This keeps your active projects organized and accessible.

Remember, archived projects can be restored at any time, so you won’t lose any valuable data. Regularly archiving old projects helps maintain an efficient workflow and ensures that you can focus on what matters most.
